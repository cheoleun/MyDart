# MyDart - DART 재무 데이터 조회 및 기업 스크리너

Open DART API와 KRX 정보를 활용하여 한국 상장 기업의 재무 데이터를 조회하고, 다양한 조건으로 기업을 필터링(스크리닝)할 수 있는 웹 애플리케이션입니다.

## 주요 기능

### 1. 재무제표 조회 페이지 (`index.html`)

-   특정 기업의 분기별/연간 재무 정보(매출액, 영업이익, 당기순이익, EPS, 총 주식수)를 조회합니다.
-   전년 동분기 대비 성장률을 함께 표시하여 직관적인 데이터 비교가 가능합니다.
-   '연결' 또는 '개별' 재무제표를 선택하여 조회할 수 있습니다.
-   매출액, 영업이익, 당기순이익, EPS에 대한 TTM(최근 4분기 합산) 추이 그래프를 제공하여 시각적인 분석을 돕습니다.

### 2. 기업 스크리너 페이지 (`screener.html`)

-   **상장 기업 정보 업데이트:** KRX(한국거래소)에서 제공하는 엑셀 파일을 기반으로 코스피/코스닥 상장 기업 목록을 생성하고 로컬에 저장합니다. (최초 1회 필수 실행)
-   **조건 검색:** 다양한 재무 성장률 조건(분기별/연간)을 조합하여 원하는 기업을 필터링합니다.
-   검색된 기업의 주요 성장률 지표를 테이블 형태로 보여줍니다.

## 기술 스택

-   **Backend:** Python, Flask, pandas
-   **Frontend:** HTML, CSS, JavaScript (Chart.js)
-   **Data Source:** Open DART API, KRX

## 설치 및 실행 방법

1.  **API 키 설정**

    -   프로젝트 루트 디렉터리에 `.env` 파일을 생성합니다.
    -   파일을 열고 DART API 인증키를 다음 형식으로 추가합니다.

    ```
    DART_API_KEY="YOUR_API_KEY_HERE"
    ```

2.  **Python 가상환경 생성 및 활성화**

    ```bash
    python -m venv venv
    # Windows
    .\venv\Scripts\activate
    # macOS / Linux
    source venv/bin/activate
    ```

3.  **필요한 라이브러리 설치**

    ```bash
    pip install -r requirements.txt
    ```

    ```bash
    python finance_gemini.py
    ```

5.  **웹 애플리케이션 사용**
    -   웹 브라우저를 열고 `http://localhost:5003` 주소로 접속합니다.
    -   **기업 스크리너 페이지 사용법:**
        1.  **(최초 1회 필수) 상장 기업 목록 업데이트:** `[상장 기업 목록 업데이트]` 버튼을 클릭하여 `market_data.json` 파일을 생성합니다. (약 5~10분 소요)
        2.  **(필수) 재무 데이터베이스 구축:**
            -   데이터를 가져올 '시작 연도'를 설정하고 `[DB 구축/이어하기]` 버튼을 클릭합니다.
            -   이 작업은 **매우 오래 걸리지만(1년치 데이터 당 약 2~3시간 예상)**, `[DB 구축 중단]` 버튼으로 언제든지 멈출 수 있습니다.
            -   나중에 다시 `[DB 구축/이어하기]` 버튼을 누르면 이전에 중단했던 부분부터 작업을 재개합니다.
        3.  두 가지 사전 준비 작업이 모두 완료되면, 스크리닝 조건을 설정하고 '검색' 버튼을 눌러 결과를 확인할 수 있습니다.
